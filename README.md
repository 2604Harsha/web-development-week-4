# GameZone – Gaming Discovery Website

## About the Project

GameZone is a front-end web project created to make discovering games simple and enjoyable. It brings together games from different categories in one place, allowing users to browse the collection, search for specific games, and explore their descriptions before choosing one.

The website features a dark gaming theme with neon-green highlights, interactive elements, and a responsive layout that adapts to different screen sizes. It was developed as part of the **Week 4 Web Development Task** using HTML, CSS, and JavaScript, without requiring a backend or database.

## Features

- **Gaming Home Page:** A landing page introducing GameZone with navigation and an overview of the website.
- **Game Collection:** Six game cards featuring images, names, categories, and short descriptions.
- **Live Search:** Find games by typing a game name, category, or related keyword.
- **Game Details:** View additional information about a selected game.
- **Play Interaction:** Clicking a Play button displays the required message, `Game is starting...`.
- **Responsive Design:** A layout designed to work on desktops, tablets, and mobile devices.
- **Mobile Navigation:** A collapsible navigation menu for smaller screens.
- **Interactive Styling:** Hover effects, smooth scrolling, and visual transitions for a better browsing experience.
- **Search Feedback:** Displays matching results and an appropriate message when no games match the search.

## Getting Started

### Prerequisites

- A modern web browser, such as Google Chrome.
- Visual Studio Code or another code editor.
- An internet connection for externally hosted images, fonts, and icons.

### Installation and Execution

1. Download the project files or clone the repository from GitHub.
2. Open the `GameZone` folder in Visual Studio Code.
3. Check that `index.html`, `css/style.css`, and `js/script.js` are in their correct locations.
4. Open `index.html` directly in your browser, or run it using the Live Server extension in VS Code.
5. Navigate to the Games section and test the search, Details, and Play buttons.

No backend server or database setup is required.

## Testing

The website can be tested using the following scenarios:

- Search for a game by its name, such as `Neon Velocity`.
- Search by category, such as `Racing`, `Action`, or `Sports`.
- Enter a keyword that does not match any game and verify that the no-results message appears.
- Clear the search and confirm that all six games return.
- Click a Details button and check the displayed game information.
- Click a Play button and verify that the expected alert appears.
- Resize the browser window to check the responsive layout and mobile navigation.

## Project Objective

The main objective of this project is to apply front-end web development concepts by building a functional and visually appealing gaming website. It demonstrates the use of semantic HTML, CSS layouts and media queries, JavaScript event handling, dynamic content rendering, and real-time search functionality.
